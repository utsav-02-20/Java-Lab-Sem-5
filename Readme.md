# Java Lab - Semester 5

This repository contains Java programming lab exercises covering basic syntax, input handling, calculations, control flow, arrays, and introductory classes and objects.

## Labs

- **Lab 1:** Hello World, student details, and pattern printing.
- **Lab 2:** Arithmetic expressions, swapping numbers, binary conversion, factorial, and simple interest.
- **Lab 3:** Electricity billing, marks and averages, currency conversion, and employee salary calculation.
- **Lab 4:** Project grading, movie ticket pricing, weekly expenses, game scores and winning streaks, canteen billing, and movie ratings.

## Running a Program

Compile and run a file from its lab directory:

```bash
javac FileName.java
java FileName
```

Most programs in Labs 3 and 4 accept values through the console using `Scanner`.
