# Java Lab - Semester 5

This repository contains Java programming lab exercises covering basic syntax, input handling, calculations, control flow, arrays, and introductory classes and objects.

## Labs

- **Lab 1:** Hello World, student details, and pattern printing.
- **Lab 2:** Arithmetic expressions, swapping numbers, binary conversion, factorial, and simple interest.
- **Lab 3:** Electricity billing, marks and averages, currency conversion, and employee salary calculation.
- **Lab 4:** Project grading, movie ticket pricing, weekly expenses, game scores and winning streaks, canteen billing, and movie ratings.
- **Lab 5:** Single, multilevel, hierarchical, and multiple inheritance, method overriding, and the `super` keyword.
- **Lab 6:** Exception handling, interface implementation and inheritance, and runtime polymorphism.

## Running a Program

Install a Java Development Kit (JDK), then compile and run a program from its lab directory:

```bash
javac FileName.java
java ClassName
```

Replace `FileName.java` with the source file and `ClassName` with the class that contains the program's `main` method. Most programs in Labs 3 and 4 accept values through the console using `Scanner`.
